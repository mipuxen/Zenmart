# 🛒 Zenmart

**An e-commerce storefront for electronics, built with HTML and CSS as a front-end learning project.**

Zenmart is an online shop concept for electronics: TVs, headphones, smart watches, consoles and more. I built it from a design file, page by page, to practise turning a design into working HTML and CSS.

> 🌱 This is one of my first front-end projects. It isn't perfect, and it isn't meant to be. It's a step along the way, and bigger projects are coming. More to build, more to learn.

---

## ✨ What's on the homepage

- **Navbar**: logo, category search bar, wishlist, account, and a cart with an item count and total
- **Hero section**: a main promo banner plus two product offer cards
- **Service bar**: free shipping, money-back guarantee, 24/7 support, flexible payment
- **Shop by Category**: six category cards
- **Top Selling Products**: a product carousel with navigation arrows, built with Swiper.js
- **Promo banner**: a full-width membership ad
- **Headphones section**: one featured product with four sub-category cards
- **TV & Home Theatre**: product cards with ratings, prices and old prices
- **Top Deals of the Day**: a countdown timer block with deal products
- **Footer**: contact info, support links, social media, app links and payment methods

## 🛠️ Built with

## 📁 Project structure

```
zenmart/
├── index.html          # Homepage
├── product/            # Product pages (all, chosen product)
├── order/              # Cart page
├── other/              # About, contact, login
└── public/
    ├── css/            # Shared + page styles
    ├── images/         # Icons, products, categories
    └── javascript/     # Scripts
```

## 🚀 Run it locally

No build step is needed. Clone the repo and open `index.html` in your browser:

```bash
git clone https://github.com/mipuxen/zenmart.git
cd zenmart
open index.html        # macOS
```

Or use the **Live Server** extension in VS Code.
